Personal project · Open source 2026

pdfRED

Local-first PDF processing console

Cloud PDF converters mean uploading sensitive files to someone else's server. pdfRED is a fast, lightweight PDF toolkit that runs entirely on your own machine — no uploads, no external API keys, no tracking. It merges, splits, rotates, compresses and converts PDFs to Word, Excel, PowerPoint, Markdown or images, plus editing, annotation, form fields, AES-256 encryption and watermarking, all from one console with a live preview and a built-in light/dark toggle.
